# AI Study Assistant using LangGraph

## About the Project

AI Study Assistant is an AI-powered chatbot that helps students understand topics, explore programming concepts, and plan their studies using simple, clear responses.

## Technologies Used

- Python
- LangGraph
- LangChain
- Google Gemini
- Gradio
- Google Colab

## Features

- Answers study-related questions.
- Explains concepts in simple English.
- Helps students create study plans and quizzes.
- Uses LangGraph to manage the chatbot workflow and conversation state.
- Provides a web-based chat interface using Gradio.
- Supports separate browser sessions for conversations.

## How to Run

1. Open the `AI_Study_Assistant_LangGraph.ipynb` notebook in Google Colab.
2. Configure your Google Gemini API key securely using Colab Secrets.
3. Run the notebook cells in order.
4. Launch the Gradio interface.
5. Open the generated link to interact with the chatbot.
